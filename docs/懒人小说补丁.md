## 1. 管理员代充兑换码接口 (AdminTopUp)

**用途**：lanmao-service 通过管理员身份调用此接口，为指定用户兑换充值码，实现 APP 端兑换 New-API 后台创建的兑换码。

### 修改文件

#### 1a. `controller/redemption.go`

在 import 中增加 `"errors"` 包，文件末尾新增 `AdminTopUp` 函数：

```go
// import 中新增：
import (
	"errors"
	// ... 其他已有 import
)

// 文件末尾新增：

// AdminTopUp allows an admin to redeem a code on behalf of a specified user.
func AdminTopUp(c *gin.Context) {
	var req struct {
		Key    string `json:"key"`
		UserID int    `json:"user_id"`
	}
	if err := c.ShouldBindJSON(&req); err != nil {
		common.ApiError(c, err)
		return
	}
	if req.Key == "" || req.UserID == 0 {
		c.JSON(http.StatusOK, gin.H{
			"success": false,
			"message": "key and user_id are required",
		})
		return
	}
	quota, err := model.Redeem(req.Key, req.UserID)
	if err != nil {
		if errors.Is(err, model.ErrRedeemFailed) {
			c.JSON(http.StatusOK, gin.H{
				"success": false,
				"message": "redeem failed: invalid or used code",
			})
			return
		}
		common.ApiError(c, err)
		return
	}
	c.JSON(http.StatusOK, gin.H{
		"success": true,
		"message": "",
		"data":    quota,
	})
}
```

#### 1b. `router/api-router.go`

在 `redemptionRoute` 路由组中新增一行：

```go
redemptionRoute.POST("/topup", controller.AdminTopUp)
```

完整上下文（约第 267-278 行）：

```go
redemptionRoute := apiRouter.Group("/redemption")
redemptionRoute.Use(middleware.AdminAuth())
{
    redemptionRoute.GET("/", controller.GetAllRedemptions)
    redemptionRoute.GET("/search", controller.SearchRedemptions)
    redemptionRoute.GET("/:id", controller.GetRedemption)
    redemptionRoute.POST("/", controller.AddRedemption)
    redemptionRoute.PUT("/", controller.UpdateRedemption)
    redemptionRoute.POST("/topup", controller.AdminTopUp)       // <-- 新增
    redemptionRoute.DELETE("/invalid", controller.DeleteInvalidRedemption)
    redemptionRoute.DELETE("/:id", controller.DeleteRedemption)
}
```

### 接口说明

- **路径**: `POST /api/redemption/topup`
- **鉴权**: AdminAuth（需管理员 access token）
- **请求体**:
  ```json
  {
    "key": "兑换码字符串",
    "user_id": 123
  }
  ```
- **响应**:
  ```json
  {
    "success": true,
    "message": "",
    "data": 500000
  }
  ```
  `data` 为充入的 quota 数值。
- **内部逻辑**: 直接复用 `model.Redeem(key, userId)`，该函数会在事务中完成：按 key 查找兑换码、校验状态和过期时间、增加用户 quota、标记兑换码为已使用(status=3)。
